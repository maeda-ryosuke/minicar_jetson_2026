# コマンドリスト

`docker compose exec` は `bash -c "..."` で包む(直接 `ros2` を呼ぶと ROS 環境が読まれない)。

## これさえ実行すれば動く
・micro_ros_agentを起動(m5stackからデータ受取)
ros2 run micro_ros_agent micro_ros_agent serial --dev /dev/ttyACM0 -v6

ros2 launch kalmanfilter ekf.launch.py

sudo docker compose exec jetson bash -c "ros2 launch minicar_bringup slam_localization_amcl.launch.py \
  initial_x:=0.0 initial_y:=0.0 initial_yaw:=0.0"

sudo docker compose exec jetson bash -c "ros2 launch minicar_nav2 nav2_mppi.launch.py"

sudo docker compose exec jetson bash -c "ros2 launch minicar_raceline raceline.launch.py

sudo docker compose exec jetson bash -c "ros2 launch minicar_motor motor_driver.launch.py throttle_map_u:="[-0.5,-0.10,0.0,0.5714,0.5714,0.6122,0.6531,0.6939]""



## Jetson(実機)

`cd ~/workspace/workspace_2026/minicar_jetson_2026`

### ホスト(先に起動)

```bash
# マイコン(エンコーダ・IMU)
ros2 run micro_ros_agent micro_ros_agent serial --dev /dev/ttyACM0
# EKF
ros2 launch kalmanfilter ekf.launch.py
```

### コンテナ

```bash
# ビルド
docker compose build jetson
# 起動(センサ自動起動)
docker compose up -d
# 起動(カメラ込み)
ENABLE_CAMERA=true docker compose up -d jetson
# 停止
docker compose down
# ログ
docker compose logs -f jetson
# シェル
docker compose exec jetson bash
```

### 確認

```bash
# scan
docker compose exec jetson bash -c "ros2 topic hz /scan"
# EKF
docker compose exec jetson bash -c "ros2 topic hz /odometry/filtered"
# TF
docker compose exec jetson bash -c "ros2 run tf2_ros tf2_echo odom base_link"
docker compose exec jetson bash -c "ros2 run tf2_ros tf2_echo map base_link"
```

## リプレイ(PC)

`cd ~/Docker/jetson_humble`

### コンテナ

```bash
# ビルド(src を変えたら毎回)
docker compose --profile replay build replay
# 起動
docker compose --profile replay up -d replay
# 停止
docker compose --profile replay down
# rviz の画面転送許可(ログインごと)
xhost +local:
# シェル
docker compose exec replay bash
```

### rviz(再生より先に起動)

```bash
docker compose exec replay bash -c "rviz2 -d /tools/bag_analysis/amcl_compare.rviz --ros-args -p use_sim_time:=true"
```

### 自己位置推定・走行

```bash
# AMCL(初期姿勢は maps/track_v1.md)
docker compose exec replay bash -c "ros2 launch minicar_bringup slam_localization_amcl.launch.py \
  use_sim_time:=true initial_x:=-0.09 initial_y:=0.02 initial_yaw:=-0.0122"
# AMCL(パラメータ指定)
docker compose exec replay bash -c "ros2 launch minicar_bringup slam_localization_amcl.launch.py \
  use_sim_time:=true amcl_params_file:=/replay_params/<名前>.yaml initial_x:=-0.09 initial_y:=0.02 initial_yaw:=-0.0122"
# slam_toolbox localization
docker compose exec replay bash -c "ros2 launch minicar_bringup slam_localization.launch.py \
  use_sim_time:=true posegraph_file:=/maps/track_v1"
# SLAM(mapping)
docker compose exec replay bash -c "ros2 launch minicar_bringup slam_mapping.launch.py use_sim_time:=true"
# Nav2 MPPI(開ループ)
docker compose exec replay bash -c "ros2 launch minicar_nav2 raceline_mppi.launch.py \
  use_sim_time:=true raceline_file:=/maps/raceline.csv"
# Nav2 MPPI(開ループ、候補軌道 /trajectories を出す。trajectory_step は 1000 本中の間引き)
docker compose exec replay bash -c "ros2 launch minicar_nav2 raceline_mppi.launch.py \
  use_sim_time:=true raceline_file:=/maps/raceline.csv visualize:=true trajectory_step:=50"
```

### 再生

```bash
# /tf に map→odom なし(例: 20261006_localization_fast)
docker compose exec replay bash -c "ros2 bag play /bags/<bag> --clock \
  --topics /scan /tf /tf_static /odometry/filtered"
# /tf に map→odom あり(例: 202610101840)
docker compose exec replay bash -c "ros2 bag play /bags/<bag> --clock --remap /tf:=/tf_bag \
  --topics /scan /tf /tf_static /odometry/filtered"
# ↑ のときに併用(odom→base_link だけ中継)
docker compose exec replay bash -c "python3 /tools/slam_sweep/tf_relay.py --raceline /maps/raceline.csv"
# Nav2 だけ再実行(SLAM・AMCL は起動しない。bag の /tf をそのまま使い、nav2・raceline の出力は流さない)
docker compose exec replay bash -c "ros2 bag play /bags/202610101840 --clock \
  --topics /scan /scan_filtered /imu /odom /odometry/filtered /tf /tf_static /map /map_metadata"

# ↑ の結果を記録(Nav2 の後・再生の前に起動)
docker compose exec replay bash -c "ros2 bag record -o /bags/<bag>_mppi_replay --use-sim-time \
  /clock /tf /tf_static /trajectories /transformed_global_plan /cmd_vel_raw /odometry/filtered /raceline/lap /map"
```

### パラメータ

```bash
# AMCL の既定値をコピー
cp src/minicar_bringup/config/amcl_localization.yaml replay_params/<名前>.yaml
```

### 分析

```bash
# bag → 分析用データ
docker compose exec replay bash -c "python3 /tools/bag_analysis/extract_run.py /bags/<bag> /bags/<bag>/analysis/run.npz"
# 周回ごとの重ね合わせ・一致率(ホスト)
python3 tools/bag_analysis/pose_error.py bags/<bag>
# AMCL 条件の一括実行(ホスト、条件は tools/slam_sweep/amcl_conditions.yaml)
python3 tools/slam_sweep/amcl_sweep.py --bag <bag>
# 条件の比較表(ホスト)
python3 tools/bag_analysis/compare_runs.py bags/<bag> replay_params/sweep/amcl/<bag>
# 1条件を結果bagに記録(ホスト)
python3 tools/slam_sweep/amcl_sweep.py --bag <bag> --only <条件> --record
# コンテナが作ったファイルの所有者を戻す
sudo chown -R $USER bags replay_params
```
